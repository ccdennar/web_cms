# Sweet Crumb Bakery — Frontend

Next.js 14 (App Router) storefront for a bakery. Talks to a Payload CMS backend
over its REST API.

## Run

1. Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_PAYLOAD_URL`.
2. `npm install && npm run dev` → http://localhost:3000

The backend must be running first (see `../SETUP.md`).
